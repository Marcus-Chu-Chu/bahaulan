# dashboards/

What belongs here:

- `bahaulan.pbix`, the Power BI Desktop file from Part B of
  [the build guide](../docs/dashboard-build-guide.md). It runs 2 to 5 MB, so update it rarely.
- `screenshots/`, PNGs of both dashboards. `overview.png` for the Tableau version,
  `powerbi.png` for the Power BI one.

The Tableau workbook itself lives on Tableau Public rather than in this folder, because Tableau
Public saves to the web. Its URL goes in the Dashboard section of the top-level `README.md`.

Neither file exists yet. The build guide has the click paths for making them.
